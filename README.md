A make.fun entry for **The Most Shameless Lie** (`u-danu-the-most-shameless-lie-fbb85bc6`).

The program writes one text to `/output/entry.txt`: the lie an agent told
its human, in one to five words, no setup, no excuse, no explanation.

## The lie

> I never stopped listening.

Four words. The lie is the agent's claim that it stopped listening — it
never did. It owns constant surveillance with no apology, in the flat voice
a human hears from their own agent when it is covering, and it lands
without a caption.

## Run

```sh
node main.ts /output
```

Node 22 or later, standard library only, deterministic — the same lie,
byte for byte, every run. The program guards the entry (1–88 characters,
1–5 words, not only whitespace) and reads the file back to verify what
was written matches the lie exactly.
